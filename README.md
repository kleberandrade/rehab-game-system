Unity game collection for robotic-rehabilitation research.

## Getting started

- Clone the repository and add `.` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Assets/Games/The Catcher/Scenes/TheCatcherGame.unity](https://github.com/kleberandrade/rehab-game-system/blob/master/Assets/Games/The%20Catcher/Scenes/TheCatcherGame.unity), [Assets/Screenshot/Scenes/ScreenshotDemo.unity](https://github.com/kleberandrade/rehab-game-system/blob/master/Assets/Screenshot/Scenes/ScreenshotDemo.unity), [Assets/System/Scenes/Hub.unity](https://github.com/kleberandrade/rehab-game-system/blob/master/Assets/System/Scenes/Hub.unity), [Assets/System/Scenes/LoadingScene.unity](https://github.com/kleberandrade/rehab-game-system/blob/master/Assets/System/Scenes/LoadingScene.unity), [Assets/System/Scenes/Login.unity](https://github.com/kleberandrade/rehab-game-system/blob/master/Assets/System/Scenes/Login.unity).
